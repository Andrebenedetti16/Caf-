# Caf-
2️⃣ Preço do Café ☕ — Análise Temporal
📌 Visão Geral
Este projeto realiza uma análise dos preços do café no Brasil e no mercado internacional, avaliando variações sazonais, regionais e econômicas ao longo do tempo.

📊 Objetivos
Identificar tendências de preço por mês e ano

Avaliar fatores de influência (clima, exportações, etc.)

Visualizar séries temporais e picos de valor

🛠️ Tecnologias
Python

Pandas

Matplotlib / Plotly

Jupyter Notebook
